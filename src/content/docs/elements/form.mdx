## Overview 
Input fields can be wrapped within their own `<label>` or `<div>` tag. 

### LABEL Wrapper

```html
<label>Name 
  <input type="text" />
</label>
```

### DIV Wrapper 

```html
<div>
  <label for="name">Name </label>
  <input id="name" type="text" />
</div>
```

Make sure the attributes, `for` and `id`, correspond. 

### Without LABEL 

An `<input>` can be used without a `<label>` by supplying `aria-label` and `placeholder` attributes.

```html
<input aria-label="Name" placeholder="Your Name" type="text" />
```
